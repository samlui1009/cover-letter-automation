# Cover Letter Automation Tool 
<br>
<p>The purpose of this miniature project is to create a lightweight tool that automates the process of writing cover letters for job applications. The current output generates Docx files.   
<br>

###Usage
<br>
<p>To run this script:</p>
<ol>
    <li>Open a command-line window, and type `python cl-converter.py`</li>
    <li>When prompted by the interface, enter all pertinent information regarding the job that you wish to write the cover letter for.</li>
    <li>Upon completion, a new Word Docx file that is now populated with all prior inputs should be accessible and ready for submission.</li>
</ol>

###Library Dependencies
<br>
<p>For this project, I made use of a well-known Python libraries/modules.</li>
<ol>
<li>DocxTemplate:  A library with an easy functionality that generates Microsoft Word (.docx) documents from existing templates.</li>
</ol>
<p>For later improvements to the script, I am also hoping to install and utilize the Docx2pdf library to streamline this process with greater efficiency by permitting PDF conversions.</p>
